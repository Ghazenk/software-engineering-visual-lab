Extreme Programming (XP)
A way of developing software through small changes, frequent feedback and strong code quality.
09 / 20
What does XP mean?
Develop a small feature, test it, show it to users, and improve it — repeatedly.
THE FIVE VALUES
Communication
Talk often
Simplicity
Build what is needed
Feedback
Learn quickly
Courage
Change what is wrong
Respect
Value teammates
