# Software engineering, made visual

A carefully designed, beginner-friendly **20-slide** presentation about:

- Data Flow Diagrams (DFD): definition, symbols, Context, Level 0, Level 1 and guided flow
- Extreme Programming (XP): what it is, values, practices and a simple test-driven development simulation
- Scrum: the framework, three accountabilities, five events, three artifacts and a guided task board
- The 14 XP principles (simplified explanations)

All examples use a **fictional laboratory management system** called MediLab.

## Present in a browser

Open `index.html` or deploy this folder to Vercel as a static site. Use **←** and **→** to move slides. On slides 8, 12 and 18, click the simulation button to advance one step at a time. Press **F** for full screen.

## PowerPoint

Download `software-engineering-made-visual.pptx` from the site or repository. It contains **20 editable 16:9 slides** built with native PowerPoint text, geometric shapes and line connectors. The JavaScript simulations remain browser-only; PowerPoint shows the corresponding static diagrams and stages.

## Sources and scope

Scrum terminology follows the [Scrum Guide (2020)](https://scrumguides.org/scrum-guide.html). XP values/principles draw on Kent Beck and Cynthia Andres, *Extreme Programming Explained* (second edition). DFD notation uses a consistent Gane–Sarson-style store symbol. Examples are deliberately simplified and not a production-ready laboratory design.

No framework, build step or environment variables are required.
